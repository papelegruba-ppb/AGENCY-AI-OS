Regla de integración

Una tarjeta no significa que una herramienta esté conectada. Solo se automatizan acciones cuando existe API o conector autorizado. Si no existe, el orquestador continúa con código propio y entrega una web nueva o un recurso descargable.

ORQUESTACIÓN

Selección dinámica de herramientas

El orquestador decide según tarea, capacidades, conexión y coste; si una integración no está disponible, genera un entregable alternativo con el constructor interno.

No se guardan API keys en el navegador. Los proveedores API necesitan secretos y límites de gasto en Cloudflare. Los accesos externos no implican control automatizado de sus aplicaciones. Shaders y Three.js se integran en código propio; ContentCore y Canva pueden requerir exportación/importación manual según sus permisos.
