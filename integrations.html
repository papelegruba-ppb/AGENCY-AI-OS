Consulta insights del proyecto Clarity asociado al token configurado globalmente. La API no permite seleccionar un proyecto por parámetro.

Requiere CLARITY_API_TOKEN y AGENCY_KV. Límite Microsoft: 10 llamadas/proyecto/día; caché y guardia preventiva local incluidas.

Configuración en Cloudflare Pages

  • AHREFS_API_KEY — secreto global de Ahrefs.
  • CLARITY_API_TOKEN — token Data Export de un proyecto Clarity concreto.
  • AGENCY_KV — binding KV requerido para caché y guardia de cuota.

Los secretos no se muestran ni se almacenan en el navegador. El token Clarity está ligado al proyecto Clarity que lo emitió; para consultar otro proyecto de Clarity se deberá sustituir el secreto global por su token correspondiente. La integración no queda asociada a proyectos del constructor.
