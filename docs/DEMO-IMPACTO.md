# Módulo Demo Impacto — Agency AI OS

## Qué incluye
- `demo-impacto.html`: comparador comercial Antes/Después con deslizador accesible por ratón, pantalla táctil y teclado.
- Tarjetas glassmorphism para rendimiento, SEO y accesibilidad.
- Captura anterior y nueva cargables desde el equipo; se usan URLs de objeto locales y no se envían a un servidor.
- Layout adaptable y soporte de `prefers-reduced-motion`.
- Enlace desde la navegación lateral del constructor a la demo.

## Abrir y desplegar
Abre `demo-impacto.html` en un navegador o publícalo junto con `index.html` en GitHub Pages / Cloudflare Pages. No necesita proceso de build. Tailwind se carga desde CDN, por lo que sus utilidades requieren conexión a Internet.

## Importante: métricas
Las puntuaciones 35/50/42 y 98/100/95 son ejemplos visuales ficticios. No son resultados reales de Lighthouse/PageSpeed. Antes de una presentación comercial, reemplázalas por datos medidos bajo condiciones comparables.

## Integración
La navegación lateral de `index.html` contiene un enlace directo al módulo. La demo es un archivo independiente para no alterar el flujo de creación de proyectos ni el almacenamiento local existente.
