# AI Toolbox

Módulo de catálogo de herramientas IA y generación local de prompts. No duplica el runtime de proveedores ni ejecuta llamadas de IA automáticamente.

- Catálogo por especialidad: modelos, investigación, vídeo, imagen, diseño y apps.
- Prompts adaptados a la herramienta elegida; copiar, descargar y abrir plataforma.
- Historial local de hasta 20 prompts.
- No solicita ni almacena API keys, no automatiza sesiones web ni controla interfaces externas.
- Los estados API/manual son orientativos; validar documentación, planes y permisos del proveedor antes de automatizar.
- Flow y otras plataformas sin API utilizable permanecen como flujos manuales asistidos.
