# Modo rápido responsive — Agency AI OS

## Incluye
- Briefing breve para negocio, sector, color, titular, descripción, servicios y CTA.
- Vista previa de escritorio, tablet y móvil.
- Modo presentación a pantalla completa.
- Borrador local guardado en el navegador actual.
- Descarga de landing HTML independiente y resumen copiable.
- Enlace de WhatsApp preparado si se introduce un número válido.
- Metadatos básicos, HTML semántico y estilos responsive.

## Limitaciones
- Es una plantilla local, no usa una API de IA.
- Los borradores no se sincronizan entre dispositivos.
- Descargar HTML no lo publica: para compartir un enlace público hay que subirlo a un hosting como Cloudflare Pages o GitHub Pages.
- El formulario de contacto de la maqueta no envía ni guarda leads.
- Revisar copy, enlaces, accesibilidad, privacidad y requisitos legales antes de publicar.

## Uso
Abre `modo-rapido.html` desde el repositorio o publícalo junto con `index.html`. Rellena el briefing, prueba los tamaños y descarga el HTML de la propuesta.
