# AI Resources Hub

## Incluido
- Prompt Library: seis perfiles listos para Claude Web y otros modelos.
- Skills Library: cinco procedimientos portables como texto.
- Connectors Hub: inventario honesto de enlaces, modalidad y estado.
- Compatibilidad: separa uso manual, funciones dependientes del plan y API.
- Referencias de UI Skills y Phosphor Icons.

## Claude Free
El módulo funciona sin API: copiar prompts y skills en claude.ai. No presupone disponibilidad de MCP, conectores, Skills nativas, proyectos o subagentes. Verificar siempre la disponibilidad que muestre la cuenta.

## Privacidad y coste
Las entradas guardadas se almacenan en localStorage de este navegador. No se envían a servicios externos. No se activan proveedores ni se almacenan claves. Agency Mini AI utiliza el runtime existente y requiere configuración y autorización independiente en Cloudflare.

## Pruebas manuales
1. Abrir AI Resources Hub desde la navegación lateral.
2. Cambiar entre las cuatro pestañas.
3. Buscar un prompt y copiarlo.
4. Guardar un prompt/skill y recargar: el catálogo sigue disponible y las guardas quedan en localStorage.
5. Probar en viewport móvil.
6. Confirmar que los enlaces externos abren con noopener.
